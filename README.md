
# 📄 React Doc Manager

A modern and interactive **Document Management Application** built using React.js. It features a clean user interface, smooth animations, and a responsive design to provide an engaging document management experience.

🌐 **Live Demo:** [https://react-doc-manager.vercel.app](https://react-doc-manager.vercel.app)

📂 **GitHub Repository:** [react-doc-manager](https://github.com/sahil-pawar01/react-doc-manager)

---

## ✨ Features

- **Modern UI:** Clean and visually appealing user interface.
- **Responsive Design:** Optimized for different screen sizes and devices.
- **Smooth Animations:** Interactive animations and transitions using Framer Motion.
- **Reusable Components:** Component-based architecture using React.
- **Icon Integration:** Beautiful icons using React Icons.
- **Utility-First Styling:** Modern styling with Tailwind CSS.
- **Fast Performance:** Powered by Vite for a fast development experience.

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React.js 19 | Frontend development |
| JavaScript | Application logic |
| Tailwind CSS 4 | Styling |
| Framer Motion | Animations and transitions |
| React Icons | Icons |

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/sahil-pawar01/react-doc-manager.git
```

### 2. Navigate to the Project Directory

```bash
cd react-doc-manager
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
